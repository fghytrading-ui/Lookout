# Revertible changes registry

This file lists user-tagged changes that can be reverted on command.
Future Claude sessions: when the user says one of the trigger phrases below,
find the matching commit and revert it.

How to revert (works no matter how many commits land after):
1. `git log --grep "<TAG>"` to find the original commit hash
2. `git revert <hash>` to undo it cleanly (creates a new commit that
   reverses the original). If git revert produces a merge conflict
   because later commits touched the same lines, resolve by keeping the
   later changes but removing the lines marked with the tag.
3. Build + verify nothing else broke + commit.

Every tagged change has both a unique commit-message marker AND inline
code comments containing the tag, so it can be found via either method.
